A 1024×1024 broadsheet poster summing up the world news of Thursday 26 November 2026 in one image: Hong Kong marks one year since the Wang Fuk Court fire that killed 168, Israeli judges urge prosecutors to drop the Netanyahu bribery case, a fuel tanker fire kills 31 on Cairo's ring road, Wall Street slides as AI fears deepen, and North Korea expels Switzerland's envoy. The poster (`poster.png`, typeset in `poster.html` and rendered with headless Chromium) is validated and copied to the output directory as `entry.png` by `main.ts`, using only the Node.js standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
